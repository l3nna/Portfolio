// UNREAL ENGINE PROJECT_02

UE5 LOCOMOTION SYSTEM

ADVANCED CHARACTER LOCOMOTION SYSTEM

An Unreal Engine 5.7 locomotion system focused on realistic, weighty character movement and seamless transitions between first-person and third-person perspectives.


EXPLORE SYSTEM ↓

UNREAL_ENGINE_5.7

PROJECT OVERVIEW

RE:SHIFT is a character locomotion system developed in Unreal Engine 5.7, combining animation systems, procedural movement and camera logic to create grounded and responsive character movement.

// PERSPECTIVE SYSTEM

FPS ↔ TPS

The character can seamlessly transition between first-person and third-person perspectives while maintaining consistent locomotion and animation behaviour.

01

FIRST PERSON
Camera-focused movement designed for immersive first-person gameplay.

02

THIRD PERSON
Full-body character movement with directional animation and procedural systems.

03

SEAMLESS TRANSITION
Camera and character behaviour adapt when switching between perspectives.

CORE SYSTEMS

8-WAY LOCOMOTION

Full directional movement including forward, backward, strafing and diagonal movement with smooth animation blending.

ORIENTATION WARPING

Dynamically adjusts animation orientation to match the character's movement direction.

STRIDE WARPING

Adapts animation stride to movement speed and distance for more natural locomotion.

FOOT PLACEMENT + IK

Advanced inverse kinematics keeps the character's feet aligned with uneven terrain.

CHARACTER LEAN

Adds subtle body leaning during movement to improve weight and physicality.

AIM OFFSET

Allows the upper body to aim independently from the lower-body locomotion system.

// TECHNICAL_FOCUS

ANIMATION SYSTEM

The project combines Unreal Engine animation systems, Animation Blueprints, IK, animation warping and character state logic into a single locomotion framework.

01

ANIMATION BLUEPRINTS
Movement states and animation behaviour are controlled through an Animation Blueprint.

02

INVERSE KINEMATICS
Procedural IK is used for realistic foot placement and terrain adaptation.

03

ANIMATION WARPING
Orientation and stride warping allow animations to dynamically adapt to movement.
